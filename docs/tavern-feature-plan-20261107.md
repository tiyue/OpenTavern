## 3. 共用约束

### 3.1 实现与数据边界

- 沿用 `src/app/` 业务分片和现有装配顺序，界面修改位于 `src/ui/`。新分片登记对应 manifest，不直接编辑 bundle、页面或样式生成物。
- 复用候选数据、可靠保存、提交确认和来源校验。保存失败保留原数据与可重试草稿，不出现假成功、幽灵绑定或永不释放的生成状态。
- 新增字段采用有版本的规范化与迁移；旧备份缺少字段时沿用当前行为。迁移不得自动触发模型、工具、脚本或资料外发。
- 消息、摘要、分支及索引均引用稳定 ID 和来源修订。异步结果提交前重查目标会话、角色、版本、连接和草稿状态；切换目标后拒绝迟到写入。
- 保留当前发送、摘要、消息版本、滚动定位、150 条渲染窗口和加载更早的行为。不为本方案重写存储、云同步、群聊或 MVU。

### 3.2 费用、凭据与平台

- 新功能默认不产生额外外部请求。语义索引、自动轮次、自动化及工具执行须先由用户启用并配置；显示会发送的数据类别及使用的模型/服务。
- 密钥引用与端点、协议配对。新建嵌套配置不能只依赖现有顶层敏感字段过滤，必须补充嵌套导出/恢复/云同步测试；禁止把本机密钥写入可移植内容包、普通备份、调试导出或公开源码。
- 继续兼容现有远程 HTTP、本机和 HTTPS。HTTP 不承诺 Service Worker、OPFS 或离线重新导航；不能因新增功能强制迁移现有用户来源。
- 远程 Embedding 和模型访问沿用可用连接方式；浏览器 CORS 不满足时明确失败。若必须新增代理或服务，另行列明 ECS 与 Sites 两端实现及部署范围，不默认为现有同步后端已具备。
- 远程索引失败不损坏本地原文，停止或断网不自动重放计费请求；同一请求不能悄悄切换到另一服务。

### 3.3 界面约束

沿用现有五个设置标签及浅色、深色、跟随系统主题。复杂编辑在二级面板或模态内完成；聊天页只放常用入口，手机不堆叠长表单。所有新增菜单支持点击外部收起，按钮使用语义化元素并可键盘操作。界面文案沿用现有三种语言，不引入已取消的聊天内容翻译。

## 4. 原编号 01：语义长期记忆

**实施状态（2026-11-08）**：已通过协调者本地验收，未发布；实现、文件、故障返工和真实验证证据见 [开发验收记录](tavern-feature-acceptance-20261107.md)。真实供应商、Embedding 中文质量与 iPhone 真机未验收。

**目标与使用流程**：用户在“记忆”内启用语义记忆，选择索引范围、Embedding 连接与注入预算；建立索引后，发送消息时从本会话关联的旧消息/摘要中找回相关内容，并能查看本次使用的来源。

**已有能力**：自动/手动摘要、世界书关键词激活、上下文裁剪。现有 `vectorized` 字段仅为数据兼容，不构成 Embedding 或召回流程。

**需求与边界**：

- 只索引已可靠保存的正文与有效摘要，不索引未完成流式草稿。默认范围为当前会话及其明确绑定的记忆来源，不自动检索其他私人会话。
- 索引记录原消息/摘要 ID、正文修订、分支来源、Embedding 服务/模型/维度及内容摘要。不同模型或维度的向量不得混用。
- 当前问题用于相关度检索；召回结果去重、按预算裁剪，并与最近历史和摘要重复内容去重。来源失效的片段不得注入。
- 召回片段及来源名称、修订只作为原文引用进入请求和预览，不执行 ST 宏、MVU 模板、正则或变量写入/读取，也不因此获得工具权限；普通角色、预设、世界书和历史仍按原规则处理宏。
- 提供索引状态、重建、移除和本次召回查看。编辑、删除、回复版本切换及摘要失效后，旧索引立即退出可用集合，重建成功后再替换。
- 自动索引可以归并已提交变更；请求中断时如实标记未完成，不在后台无限重试。检索失败时提示本轮未使用语义记忆，继续沿用现有上下文与摘要。
- 初次交付使用用户配置的远程 Embedding，不下载本地推理模型。资料召回与记忆召回共享索引基础，但来源范围和提示词位置分开。

**数据与接口方向**：原消息和摘要是事实源，向量是可重建派生缓存，单独进行配额管理。拟提供按来源修订的索引更新、查询和失效操作；查询返回片段、来源和分数，不直接改写历史。缓存不混入普通同步快照，换设备可从原文重新建立。

**验收**：用含相关/无关旧事的固定对话验证召回；编辑/删除/切换版本后旧片段消失；重建与刷新不丢原文；模型变更、维度错误、配额不足及停止后无混合索引、无锁残留。分别验证模拟向量的确定性选择与实际指定 Embedding 服务的中文相关性，未实测服务不得标记已支持。

**候选接入范围**：[摘要提示词](../src/app/prompt/41-prompt-summary-messages.js)、[世界书选择](../src/app/worldbook/44-worldbook-activation-selection.js)、`src/app/storage/`、`src/app/summary/`、`src/app/settings/`；检索实现在独立业务模块中新增，开工时列明具体文件及 AllowedFiles。

**源码依据**：[RisuAI Hypa 记忆流程](https://github.com/kwaroran/Risuai/blob/8e1fee403a903e0c608c2a86dfa2c3e96b93acef/src/ts/process/memory/hypav3.ts#L591)。

## 5. 原编号 02：文件资料库 / 文档 RAG

**实施状态（2026-11-08）**：已通过协调者本地验收，未发布；实现、文件、故障返工和真实验证证据见 [开发验收记录](tavern-feature-acceptance-20261107.md)。真实供应商、Embedding 中文质量与 iPhone 真机未验收。

**目标与使用流程**：用户导入设定或参考文本，在资料库中预览内容和分块，绑定到角色/会话；生成时只注入与当前问题相关的片段，可以定位来源文件与片段。

**需求与边界**：

- 首次交付明确支持 UTF-8 TXT 与 Markdown；以文件实际内容校验，拒绝空文件、非法编码及超过已公布限制的输入。PDF、Office、OCR 和网页抓取列为后续格式扩展，不在首次交付中宣称支持。
- 管理文件名称、内容、修订、索引状态和绑定；同名文件不自动覆盖。替换先生成候选，保存成功后切换，失败保留旧文件和旧绑定。
- 资料库“导出”输出真实 UTF-8 原文、正确扩展和 MIME，可经同一导入入口生成同名副本；结构化资料与绑定继续由完整/分项备份负责。重命名走原候选保存，空白/超量名称可见报错，取消或失败不改名称，名称变化不改正文修订或向量。
- 分块保留原始文本区间及必要的标题上下文；导入的 HTML/脚本仅作为资料文本处理，不能执行。
- 明确全局、角色、会话的绑定范围和优先级，默认不跨未绑定资料检索。01 与 02 共用 Embedding 配置、索引格式及查询能力，不各建一套向量服务。
- 本次提示词查看区列出实际注入的文件、修订和片段，不能只展示搜索预览；资料内容不能变成宿主指令或获得工具权限。
- 删除、解除绑定及替换会使对应召回失效。原文可导出并参与明确的备份/同步策略，向量可删除重建，不能为了清理索引删除原文。

**数据与接口方向**：拟保存独立资料实体、来源修订、内容摘要和显式绑定；资料查询输出与 01 相同的片段契约，但标记为资料来源。原始文件正文属于用户数据，需同时补充完整/分项备份及现有两套同步路径，不能只在当前浏览器暂存。

**验收**：导入 TXT/Markdown、绑定两份不同资料，验证未绑定内容不进入提示词；检索片段可追溯原文；文件替换/删除后不召回旧片段；刷新、备份恢复和另一隔离客户端同步后原文及绑定完整。包含非法输入、长文本、索引失败和保存失败测试；上线前量测并公布文件大小、总量及分块预算。

**候选接入范围**：[提示词构建](../src/app/prompt/41-prompt-builder.js)、`src/app/storage/`、`src/app/transfer/`、`src/app/sync/`、`src/ui/`；新增资料和检索业务模块。同步分段实体是否需要后端白名单变更，应先核对 `functions/sync/` 与 `server/opentavern_backend/`，不得先假定兼容。

**源码依据**：[SillyTavern 向量处理](https://github.com/SillyTavern/SillyTavern/blob/06bde939fb1e9c4c8d8641d810f0a916b5bce127/public/scripts/extensions/vectors/index.js#L572)、[附件管理](https://github.com/SillyTavern/SillyTavern/blob/06bde939fb1e9c4c8d8641d810f0a916b5bce127/public/scripts/extensions/attachments/index.js#L14)。

## 6. 原编号 03：模型连接配置档案

**实施状态（2026-11-07）**：已通过协调者本地验收，未发布；实现、文件、故障返工和真实验证证据见 [开发验收记录](tavern-feature-acceptance-20261107.md)。真实供应商、Embedding 中文质量与 iPhone 真机未验收。

**目标与使用流程**：在“连接”中新建、复制、重命名和删除命名档案；选择档案后一次切换协议、端点、模型和对应参数，不再逐项重填。

2. 所有持久化新增项验证刷新、完整/分项备份恢复；设计中参与同步的实体验证两个隔离客户端的往返与冲突。保存失败和超时保留旧数据，不产生后续模型调用。
3. 涉及生成或执行的功能验证停止、切会话、切模型、删除目标、重复点击、迟到结果与重新打开页面；不能自动重放已取消或结果未知的计费/外部动作。
4. 浏览器验证移动 390px 与桌面 1280px、浅色/深色/跟随系统、键盘及长文本；检查截图、横向溢出和 pageerror。手机 Chrome 真机结果单列，桌面模拟不得替代。
5. 测试资料、会话和模型响应使用隔离配置；真实服务测试另外记录服务、模型及结果，不暴露密钥、不修改用户真实历史。

### 18.2 构建与回归

- 修改分片或界面后通过既有构建重建生成物，运行 `npm run build`、`npm run check`；按实际接入运行 `check:private-settings`、`check:storage-timeouts`、`check:message-reliability`、`check:chat-operations`、`check:mvu`、`check:card-execution` 等相关检查。
- 扩展已有相关测试入口，新增运行测试必须进入完整检查，不只放一份无人调用的脚本；浏览器组按需要接入发布门禁。保持现有十组回归与私有数据保护。
- 发布时另运行 `npm run check:release` 并按 [ECS](ECS.md)、[Sites](SITES.md) 验证同一产物、公开资源哈希、真实浏览器及回退边界。ECS 与 Sites 分别记录，不能用一端通过代替另一端。

### 18.3 完成定义与本轮记录

单项完成需要需求、实际代码、非法输入/故障回归、浏览器截图和持久化证据一致；真实供应商、真机及部署未测项分别标明。多个阶段不得以“已搭框架”笼统报完成。
